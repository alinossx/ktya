# Сайт-подарок на день рождения для Катеньки 🎂

## Как запустить

1. Скачай все файлы из этой папки.
2. (По желанию) Положи файл песни `music.mp3` рядом с `gothic.html` (песня "The Red Means I Love You" — Madds Buckley).
3. Открой `index.html` в браузере.

## Как залить на GitHub Pages

1. Создай новый репозиторий на GitHub.
2. Загрузи все файлы в корень репозитория.
3. Зайди в Settings → Pages → Source: Deploy from a branch → Branch: main → Save.
4. Через пару минут сайт будет доступен по адресу:
   `https://твой-ник.github.io/название-репозитория/`

## Структура
мрмвоа
- `index.html` — главная (сердце из точек)
- `gothic.html` — тёмная страница с песней и розой
- `letters.html` — письма от персонажей Гарри Поттера
- `cake.html` — торт + шампанское + конфетти
- `gifts.html` — подарки с деньгами и золотом
- `final.html` — финальное послание
- `style.css` + `heart.js` — стили и анимация сердца
